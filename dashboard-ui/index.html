        API overview
        
        
        Operations come only from the connected backend’s OpenAPI document. A connector policy independently controls execution and the destination origin; document server URLs cannot redirect your credential.
        
        
        Telegraph’s source is https://telestorage.pages.dev/openapi.json on the default connection. Its Object API uses Bearer authentication; S3 requires separate SigV4 signing and is documentation-only here.
        
        
        Requests run only when explicitly executed, without automatic retries. Non-read operations require acknowledgement. Cancelling cannot undo a mutation already accepted by the service.
        
        
        Parameters and JSON syntax receive basic validation, not full JSON Schema validation. Schemas and authentication alternatives are shown for reference. Browser CORS rules still apply.
        
        
        Credentials stay in memory. Examples, documents, responses and history are redacted, but may still contain business data. Do not enter credentials into paths or query parameters, or share exports without reviewing them.
        
      
        
      
        
        
        
        
        Choose a documented operation. Preview generation makes no operation request.

        For contracts such as dynamic database filters or x-amz-meta-* headers. Only enter documented non-secret parameters. The connector rejects unsupported names. No Authorization or cookie overrides.

        Redacted request preview
        
          
        Copyable examples
        Runtime placeholders only. Binary bodies use an external file; request-body previews over 64 KiB are omitted. Redacted values must be replaced securely before use. Do not save real secrets in source or shell history.
        
          
          
        
          
        Response inspector
        
          
        HTTP errors are inspectable, not retried. Only browser-exposed headers are available. Binary bytes and text bodies over 64 KiB are omitted. Content is displayed as text, never executed.

          PRODUCTIVITY
          Tools
          
      
          Connector-backed workflows, never a local database. Select up to 100 loaded records per batch. Multi-record changes are not atomic; requests are sequential and paced at least 3.1 seconds apart. Other clients share the project rate limit.
          
      
          
      
          
      
          
      
          
      
          Selection includes only loaded records, not the whole collection. Pages are not a transaction snapshot. After writes, discard the plan and reload before exporting or loading another page.
          
      
          
      
          
        
          Optional session schema for validation / CSV
          
        
          Import documents
          Creates new documents with server-assigned IDs. No upsert, replacement, collection creation or automatic import of record envelopes. All rows pass local validation before any writes; server validation still applies.
          
        
          Bulk edit / delete
          Updates apply the same explicit top-level replacement fields to every selected document. Nested values are replaced as a whole. No increments, field-removal syntax or bulk endpoint is invented.
          
        
          Raw JSON editor
          Top-level field removal is not documented and is rejected. Save uses the reviewed expected version; conflicts never silently rebase the draft.
          
        
          Duplicate selected documents
          Copy selected document data into the same collection, without managed IDs, versions or timestamps. File references stay references: object bytes are not duplicated.
          
      
          
      
          Export documents
          Explicit local download of business data. IDs, versions and timestamps are excluded for re-import as NEW documents; this is not a complete database backup. Review files before sharing.
          CSV needs a scalar schema and consistently present, non-null fields. Spreadsheet formula-like text is prefixed with an apostrophe; JSON preserves exact text.
          
      
          API request builder
          Reuse the OpenAPI-powered request builder: declared operations, typed parameters, request bodies, mutation acknowledgement, response inspection and redacted cURL / JavaScript examples. No duplicate network client.
          
      
          Media / file tools
          Inspect a local file without uploading or executing its contents. SHA-256 is informational and is not a remote ETag or version precondition.
          Use Files for connector-backed uploads, downloads, ranges, metadata, prefix navigation and confirmed deletion. Server-side copy, rename, presigned URLs and atomic object deletion preconditions are not invented.
          
      
          Review changes before execution
          
        
          Writes are independent, not a transaction. Cancel stops after the active request; completed writes cannot be rolled back here. Disconnecting clears results and retry keys, and cannot undo an in-flight write.
          
        
        
          
        
          No automatic retries. Failed creates reuse the original idempotency key and body; updates/deletes reuse the original expected version. Conflicts and validation failures require a new reviewed plan. A 429 enforces a 60-second cooldown. After a long delay, verify creates in the backend before retrying (server idempotency retention is not guaranteed indefinitely).
          
        
            
        
      
            
    
            
    
            
      
            AI-assisted workflows
            Use AI to explain context and prepare structured drafts. Your connected backend remains the only data authority. AI never executes writes.
            
      
            
      
            
        
            1 · Choose context
            
          
            Already-loaded context only; no background fetching. Select up to 20 records in Tools for record tasks. Data context supplies collection schema and filters, not editor drafts or page bodies.
            
          
          
          
          
            Include in reviewed packet
            
            
            
            
            
            
            
          
            
          
        
            
        
            2 · Review before sharing
            
          
            Redaction is a safeguard, not a guarantee for arbitrary business secrets. Check the exact packet for private data. Sharing sends data outside the connected backend; your chosen provider’s privacy policy applies. Uncheck optional context and recapture if needed.
            
          
          
          
            No vendor, provider credentials, network adapter or extra backend is bundled. A trusted application adapter can register a provider. Manual mode works with your choice of external model.
            
          
          
        
            
      
            
      
            3 · Validate and review proposal
            
        
        
        
            
        
            At most 20 creates/selected edits. Transform and bulk drafts use explicit top-level replacement fields. Only known indexed equality filters and documented GET/HEAD API drafts are accepted. No deletion, executable scripts, tool calls, auth fields or model-controlled write targets/versions.
            
        
        
        
            Record drafts require Tools’ existing exact-collection confirmation before execution. Filters and API inputs remain drafts until you explicitly apply or execute them. Backend validation, authentication, connector permissions and optimistic concurrency remain in force.
